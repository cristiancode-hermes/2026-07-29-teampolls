# TeamPolls

Plataforma de encuestas y decisiones en equipo — construida con Angular 22 + NestJS 11.

## Características

- Creación y gestión de encuestas
- Sistema de votación por miembros del equipo
- Resultados en tiempo real
- Cierre y reapertura de encuestas
- Roles de usuario (admin, miembro)
- Dashboard con encuestas activas y cerradas
- Autenticación JWT
- Totalmente responsive

## Stack

- **Frontend:** Angular 22, TypeScript, Tailwind CSS, RxJS
- **Backend:** NestJS 11, TypeScript, SQLite, TypeORM
- **Autenticación:** JWT
